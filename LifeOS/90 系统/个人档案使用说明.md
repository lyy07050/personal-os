# 个人档案使用说明

个人档案放在 `60 个人档案/`，有两篇：`个人档案`（身体数据、尺码）和 `账号密码`。
这个文件夹**不上传**任何地方：不进 GitHub、不进 iCloud、Obsidian Sync 排除，Claude 和任何 AI 都不读。

## 第一次：建模板

在终端运行一次（只会建空模板；已经有内容的笔记不会被覆盖）：

```
python3 tools/make_private.py
```

## 装 Meld Encrypt

Obsidian → 设置 → 第三方插件 → 浏览 → 搜 **Meld Encrypt** → 安装 → 启用。
建议在它的设置里把「记住密码」设成「直到关闭 Obsidian」或关掉，离开电脑时就锁上了。

## 填写和加密

1. 打开 `个人档案`，在表格里填好体重、尺码等。
2. 选中「身体数据」那一节（从标题下面的表格开始，到表格结束），按 `Cmd + P`，输入 **Meld Encrypt: Encrypt/Decrypt**，回车，设密码 A（要输两次）。「尺码」那一节同样做一次，用同一个密码 A。
3. 打开 `账号密码`，选中整张表格，同样加密，**用另一个密码 B**。
4. 加密后那一段会变成一串乱码。想看或改：点那一段（或选中它再用一次同一个命令），输入密码；改完再加密回去。

密码请记在你自己的地方（比如手机自带的「密码」App），**不要**发给 Claude，也不要写进仓库的任何笔记。

## 手机上的副本

1. 手机上也装 Meld Encrypt。
2. 电脑上加密好之后，用 **AirDrop**（或数据线）把 `个人档案.md`、`账号密码.md` 两个文件发到手机，放进手机仓库的 `60 个人档案` 文件夹。
3. 以后电脑上改了，再 AirDrop 一次覆盖手机上的旧文件。手机上尽量只看不改，免得两边不一样。

## 确认没有上传

- **Obsidian Sync**：设置 → 同步 → 排除的文件夹 → 加上 `60 个人档案`（Sync 排除）。
- **iCloud**：这个仓库不放在 iCloud 文件夹里。
- **GitHub**：`.gitignore` 已经排除 `LifeOS/60 个人档案/`，提交时不会带上。
