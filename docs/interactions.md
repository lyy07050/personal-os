# 交互说明书（人生 OS · Obsidian 面板）

更新：2026-11-21 · 适用于电脑版面板（`lifeos-desk`）。手机版（`m-*` 页面）还没有跟上这里的编辑、删除功能。

这份文档说明**现在**每个页面能做什么、点了会发生什么、改的是哪个文件的哪一行。照着它，加上 `CLAUDE.md` 的数据格式，别人可以把这套交互重新做出来。
为什么要这样做见 `PRODUCT.md`，长什么样见 `DESIGN.md`，每个功能当时的设计讨论见 `docs/superpowers/specs/`。

---

## 0. 怎么实现的（一句话版）

- 没有数据库：数据就是仓库里的 Markdown 文件（一行一条，或一张卡一篇笔记）。
- 每个面板笔记里有一个 `dataviewjs` 块，调用 `90 系统/views/<页面>/view.js` 画出页面（Dataview 插件，需开启 JS 查询）。
- 共用代码：`views/_shared/lib.js`（`L`，纯函数 + 小部件）、`data.js`（`D`，读写各种数据）、`vault.js`（`V`，个人档案加密）、`food.js`（食物图标）。
- 写文件只用 Obsidian 的 API：`app.vault.create`（新建）、`app.vault.process`（改正文）、`app.fileManager.processFrontMatter`（改属性）、`app.fileManager.renameFile`（改名）、`app.vault.trash(f, true)`（放进系统废纸篓）。
- 样式在 `.obsidian/snippets/lifeos.css`，所有选择器都以 `.lifeos-dash` 开头，不影响其他笔记。

## 1. 共同规则（每个页面都一样）

### 1.1 添加
- 卡片右上角的 **＋** 或横幅上的按钮 → 展开一个小表单（或弹出小窗口）。
- 填完点「加上 / 保存」→ 立刻写进对应文件，并马上出现在页面上（不用刷新）。
- `Esc` 或再点一次 ＋ 收起表单。

### 1.2 编辑
- **点东西本身**（名字、一行、一张卡）→ 弹出编辑小窗口，里面已经填好原来的内容。
  可以点的文字，鼠标移上去会出现淡淡的下划线（`.editable`）；卡片和表格行整块可点（`role="button"`，键盘 `Enter` 也能打开）。
- 「保存」→ 写回**数据原来在的地方**（那一行 / 那篇笔记的属性），页面上原地更新。
- 有自己笔记的东西，窗口里有「打开笔记」，跳到原笔记去写长内容。
- 共用组件：`L.editSheet(root, { title, fields, values, onSave, onDelete, openPath })`；记账用专门的 `L.moneySheet`（金额大字号）。

### 1.3 删除
- 入口两个：鼠标移到那一项上出现的 **垃圾桶**（`L.delBtn`），或编辑小窗口里的「删除」。
- 点了之后：那一项先**变淡**，屏幕下方出现「「xxx」删掉了 · **撤销**」，带一根倒计时线。
  **4 秒内**点撤销 → 什么都不改；4 秒后才真的删（`L.removeWithUndo` → `L.undoable`）。
  同一时间又删了别的，上一条会先执行掉。
- 真的删的时候：
  - **一篇一篇的笔记**（随手记卡片、物品、知识卡、灵感、投递、面试、活动卡、食谱、事情、待办卡）→ 放进**系统废纸篓**（`L.trashFile`），能找回。
  - **一行一行的记录**（账单、单词、错词、食物、购物清单、日程、作业截止、订阅）→ 从文件里删掉**和原文一模一样的那一行**（`L.removeLine`，按内容找，不按行号，所以前面删过别的也不会删错）。
- **从不永久删除。** 别处来的东西（作业截止、课）在它原来的地方改；课只能「从日历隐藏」。

### 1.4 列表的通用行为
- **做完的沉底**：勾掉的项目 0.6 秒后移到列表末尾（`L.sinkDone`），没做的永远在上面（`L.doneLast`）。
- **长列表在卡片里滑**：超过高度就在卡片内部滚动，底部有渐隐（`L.scrolly`）。
- **大墙翻页**：右边 ‹ › 翻页，可以横滑（`L.pager`，每页固定张数）。
- **吃完、100% 完成** 也走撤销条（4 秒）。

### 2.1 本周日程（像苹果日历）

- **翻周**：‹ › 翻到上一周 / 下一周，「回到本周」只在不是本周时出现；翻到哪周只记在内存里，重新打开回到本周。
- **添加**：右上角 ＋ 或**点空白格子** → 「加日程」表单，日期、时间已经按点的位置填好（一格 2 小时，点在下半格 = 后一个钟点；点「全天」那行 = 全天）。填事情、选**类别**。
- **类别 = 颜色**（只给自己加的日程）：生活 黄、学校 蓝、求职 红、社交 绿、其他 紫。不选 = 生活。
- **点任何一个日程** → 小窗口，按来源决定能改什么：

| 日程来源 | 能改 | 删除 | 写到哪 |
|---|---|---|---|
| 我的日程 | 事情、日期、时间（空 = 全天）、地点、类别 | ✅ | `10 总部/日程.md` 那一行（改了日期会重新排序） |
| 作业截止（红） | 标题、日期、时间 | ✅ 删那一行 | `45 教务处/截止日期.md` |
| 活动（绿） | 标题、日期 | ✅ 卡片进废纸篓 | 活动卡的 `# 标题` 和 `date` |
| 面试（红） | 公司、日期、时间 | ✅ 笔记进废纸篓 | 面试笔记的 `company`、`date` |
| 课（蓝，每周） | 课程名、星期几、时间 | ❌ 只有「从日历隐藏」 | 课程主页的 `course`、`next_class`；隐藏 = `hide_in_calendar: true` |
| 周复盘（紫） | 不能改（每周日自动出现） | ❌ | 只有「打开」 |

别处来的日程都有「打开原笔记」。

## 3. 随手记（`00 随手记/随手记` · `views/inbox`）

- **记**：「现在想记点什么？」选 文字 / 清单 / 链接 / 活动，点「存一下」→ 新建一张卡（第一行当标题）。
- **筛选**：全部、各类型、**📌 钉住**；搜索框按标题、内容、清单项搜。从首页点「最近的活动 / Reminder」过来会自动筛好（`L.goto` + `sessionStorage` 传一次）。
- **钉到首页**：每张卡右上角 📌，点一下钉住（`pinned: true`，首页 Reminder 显示），再点取下。待办卡没有钉子。
  Reminder 显示所有钉住的卡：有清单的显示进度和勾选项，没有的显示标题和前几行；勾完了也留着，取下钉子才消失。
- **清单项**：直接在卡片上勾、在最后一行加新的一项；勾掉的沉底。
- **删**：卡片右上角垃圾桶 → 进废纸篓。
- 卡片正文：点标题打开原笔记改（长文字在笔记里改更顺手）。

## 4. 财务部（`20 财务部/财务面板` · `views/finance`）

### 4.1 记一笔 / 改一笔
- 横幅「＋ 记一笔」或首页「记一笔」→ 小窗口：金额（大字）、买了什么、分类（可选「以后再整理」= `待分类`）、方式（现金、Apple Pay、信用卡、借记卡、转账 / e-Transfer）、日期。
- 写进 `20 财务部/账本/YYYY-MM.md`：账本新的在上，插在第一条日期不晚于它的行前面；新月份自动建文件（`budget: 1400`）。
- **账单流水：点任何一行 → 「改一笔」**（同一个窗口，填好原来的内容）。保存 = 删掉原来那行再按新日期写进去，换了月份就进新月份的账本。窗口里「删掉这一笔」，或行尾垃圾桶。

### 4.2 待分类
- 认不出的商户进「待分类」，按 `分类规则.md` 猜一个，点 ✓ 确认或改选。

### 4.3 订阅（`20 财务部/订阅.md`）
- ＋：名字、金额、每月 / 每年、扣款日（每月写几号；每年写 `月-日`，如 `11-15`）、分类、方式。
- **点一行**改；垃圾桶删（已经记进账本的那几笔不动）。
- **自动记账**：每次打开财务面板或首页时（`D.chargeSubs`），到了扣款日的订阅会往当月账本写一笔：
  - 月付：本月扣款日已到、且「记到」不是本月；扣款日大于当月天数取月底（31 号在 2 月 = 28 号）。
  - 年付：只有扣款月份的那个月、日子到了才记。
  - 记完在订阅那行写 `[记到:: YYYY-MM]`，**同一个月不会记两次**；在账本里删掉那笔也不会再冒出来。
  - 本月账本里已经有**同名同金额**的一笔（之前手记过）→ 不再写，只标「记到」。
  - 新加一个订阅、本月扣款日已过 → 马上记进本月。

## 5. 食物墙（`30 后勤部/食物墙` · `views/fridge`）

- **六类方块**（生鲜、水果、调味料、粉面速食、药材、零食）：每块一页 5 样，多了 ‹ › 翻；＋ 添加（名字、数量、几天到期、位置）。
- **点食物名字**：改名字、数量、到期（空 = 不会坏）、位置、类别；位置改了会挪到 `食物.md` 里那个位置的那一节。窗口里能删。
- **吃完**：点「吃完」→ 变淡 + 撤销条 4 秒 → `食物.md` 这行打勾、名字加进购物清单。
- **购物清单**：勾 = 买到了（沉底）；点文字改；垃圾桶删。按文字找行，刚吃完加进来的也能勾、改、删。
- **今天可以做**：全部食谱，一页 3 道；冰箱里有的食材绿色。＋ 加一道菜（菜名、食材用逗号隔开、做法）→ `30 后勤部/食谱/<菜名>.md`；右上角垃圾桶删（进废纸篓）。

### 8.1 闪卡（开始学习 / 开始复习）
- 不用装插件，在面板上弹出（`L.flashcards`）。

## 9. 求职（`50 人事部/求职` · `views/career`）

- **点投递卡**：公司、职位、阶段（想投 / 已投递 / 面试中 / Offer）、日期或备注；**阶段改了卡片直接挪到那一栏**。卡片右上角垃圾桶删（进废纸篓）。

## 10. 每周复盘（`10 总部/复盘/GGGG-[W]WW` · `views/review`）

- 左侧导航「每周复盘」**直接打开本周那篇**；本周还没写就打开周复盘面板（那里有「开始本周复盘」）。
- 本周页面横幅「打开全部复盘」→ 周复盘面板（所有周的列表）。
- **下周三件要事**：每条右边一个开关「放进首页」→ 那一行末尾加 `[首页:: 是]`，出现在首页今日待办；再点拿出来。空着的那条不能放。
  旧笔记的 `goals_on_home: true`（以前的一键按钮）仍然算三条都在；第一次点开关时自动换成逐条标记。
- 习惯打卡：点圆点 = 改那天日记的属性。

## 11. 个人档案（`60 个人档案/个人档案` · `views/profile` + `_shared/vault.js`）

- **锁着**：横幅「输入密码解锁」，下面「身体数据」「尺码」「账号密码」三张灰条卡片 + 小锁。
- **第一次**：「设置密码，开始记录」→ 输两次（至少 6 位），提醒「忘记密码就再也打不开了」。「账号密码」卡片单独「设置第二个密码」。
- **解锁后**：卡片变成可以直接填的表格（可加行、删行）；停手 0.8 秒自动加密保存（显示「已加密保存 ✓」）；密码栏点进去才显示明文。
- **自动锁上**：点「锁上」、离开这一页、切到别的窗口、5 分钟没动。
- **加密**：浏览器自带 Web Crypto；密码经 PBKDF2（SHA-256，310000 次，随机 16 字节盐）变成 AES-GCM 256 位钥匙，每次保存换新 IV。笔记里只存 `%% lifeos-vault:profile v1.<盐>.<IV>.<密文> %%`（Obsidian 注释，阅读模式看不见）；账号密码是 `lifeos-vault:accounts`。密码不存在任何地方，钥匙只在内存里。
- **旧模板清理**：以前模板的明文表格完全空着 → 一打开就删掉；填过字 → 设密码时搬进加密数据再删。旧的单独「账号密码」笔记打开会提示「这篇用不到了」并提供「放进废纸篓」。
- 建模板：`python3 tools/make_private.py`（用户自己运行；只看文件大小、不读内容，已有内容的笔记不覆盖）。
- Claude 和任何脚本都不读写这个文件夹；它不进 git、不进 iCloud，Obsidian Sync 要手动排除；手机副本用 AirDrop。详见 `90 系统/个人档案使用说明`。
