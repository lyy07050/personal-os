# 面板上加、改、删 · 设计记录（短）

日期：2026-11-21 · 状态：已做完，Charlotte 在对话里逐项确认 · 现在的完整行为见 `docs/interactions.md`

## 为什么
面板一开始只会「看」：要加一条、改一个字、删一样东西，都得打开原笔记去改 Markdown，Charlotte 觉得像在用 Obsidian 而不是一个 App。她要的是：面板上看到的东西都能直接**添加、编辑、删除**，像苹果日历、像普通网页一样。

## 目标
1. 每个板块都能加：＋ 小表单，存完马上出现。
2. 每样东西都能改：点它本身就弹出编辑窗口，改的是数据原来在的地方。
3. 每样东西都能删，而且删错了能反悔。
4. 改完不用刷新、不跳去别的笔记。

## 反目标
- 同一条信息存在两个地方（编辑永远写回原处）。
- 一点就永久删掉、没法找回。
- 为了「能编辑」去碰 `60 个人档案`（Claude 不读不写）或改 Quercus 同步的标记段。
- 面板明显变慢。

## 做了哪些决定（按时间）
- **撤销**：删除、吃完、事情 100% 收起，都先变淡 + 底部撤销条；吃完原定 2 秒，Charlotte 觉得太快，统一改成 **4 秒**。撤销条挂在 `body` 上（面板里有 container 查询，`position: fixed` 会跟着面板滚走）。
- **删到哪**：一篇笔记 → 系统废纸篓（`app.vault.trash(f, true)`）；一行记录 → 按内容删掉那一行（不按行号，避免前面删过别的就删错）。
- **事情 100%**：不删笔记，标成「完成」并从首页收起。
- **随手记钉子**：每张卡都能钉到首页；Reminder 改成显示所有钉住的卡（以前只显示「钉住且有没勾完的清单」）。
- **订阅自动记账**：写真的账本行（这样月总额、分类、周复盘都算进去），用 `[记到:: YYYY-MM]` 防止重复；本月已手记过同名同金额的就不再写。
- **本周日程像苹果日历**：点空白格子加（按点的位置填日期时间）；点任何日程都能改，按来源决定能改什么；自己加的日程多了「类别 = 颜色」（新字段 `[类别:: …]`，Python 和 JS 解析同步改）；课不删，只能「从日历隐藏」。
- **复盘三件要事**：一键「放进首页」改成每条单独开关（行尾 `[首页:: 是]`），旧的 `goals_on_home: true` 兼容。
- **闪卡**：「开始学习 / 开始复习」本来调用 Spaced Repetition 插件，没装就只会打开笔记 → 改成面板自己弹闪卡，不依赖插件。
- **知识库「存一条」**：不再建空白笔记跳过去，改成页面上的表单。
- **侧栏「每周复盘」**：直接打开本周那篇；本周页的按钮改成「打开全部复盘」。
- **个人档案**：原计划（build plan Task 7）用 Meld Encrypt 插件加密明文表格，但那样表格只能放在面板外面，挤进侧栏那一列。改成照设计稿 `demo/v4/desktop-private.html`：内容在页面里、用 Web Crypto（PBKDF2 310000 次 + AES-GCM）加密存在笔记的 `%%` 注释里；第二个密码管账号密码；自动上锁。模板由用户自己运行 `tools/make_private.py` 建（Claude 的 deny 规则不绕开），脚本只看文件大小不读内容。
- **通用编辑窗口**：账单流水之后，食物、购物清单、投递、订阅、单词、事情、首页待办都用同一个 `L.editSheet`，样子和行为一致；记账单独用 `L.moneySheet`（加了「改一笔」「删掉这一笔」）。

## 方案
只考虑过一种：在现有 dataviewjs 面板里直接用 Obsidian 的 API 读写 Markdown（不加数据库、不加插件）。理由：数据格式已经固定、测试和 lint 都围着它；加数据库会让「一条信息只记一次」和「数据本地、可读」变难。

## 没做 / 留给以后
- 手机版（`m-*` 页面）还没跟上这些编辑、删除功能（原计划 todo-calendar 的 Task 5 也还没做）。
- JobSync 同步进 OS：查过它的数据库（SQLite，`prisma/dev.db`，当时 0 条投递），先不做，入口照旧。
- 知识卡、随手记卡片正文、食谱：长文字，保持「打开笔记」去改。

## 怎么验证的
每一项都在预览工具（`tools/preview/`，写入只改内存）里点过一遍并对照写出来的那一行；`tools/.venv/bin/pytest -q` 从 84 个测试增加到 114 个（包括 JS 和 Python 解析一致、个人档案加解密、测试不读 60 文件夹、用到 `D.` 的页面都加载了 data.js）。
