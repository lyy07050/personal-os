# 卡片里滑动、格子翻页、勾完排后面 · 设计（短）

日期：2026-11-21 · 状态：Charlotte 已在对话里确认

## 为什么
面板上的卡片内容一多就被截掉（「还有 N 项 →」）或把卡片撑得很长。Charlotte 想像网页一样：列表在卡片里滑着看，格子用 ‹ › 翻页；打勾后没做的留在上面。

## 做什么
1. **卡片里上下滑**（高度固定，滚轮 / 触控板只滚卡片里面，底部淡出提示还有）：首页今日待办、Reminder（每个清单显示全部条目，去掉「还有 N 项 →」）、最近的活动、事情进度（超过 5 条时）；多邻国单词本 / 错词本；教务处截止时间线；财务部账单明细。
2. **格子翻页**（‹ › + 页码 `1 / 3`，触控板左右滑也能翻，只有一页时不显示）：首页 Fridge 一页 4 个（冷藏全部，不再只取 4 个）；食物墙每个分类框一页 5 样；物品墙一页 6 张；知识库「最近的知识卡」。
3. **勾完排到后面**：今日待办、Reminder 清单、随手记里的清单、购物清单、面试准备、教务处截止。打勾先盖章，约 0.6 秒后这一行滑到最后；取消勾回到没做的那一组最后。打开时就按「没做的在前、做完的在后」排（只改显示顺序，不改文件）。最近的活动没有勾选框，不适用。

## 不做
不改数据文件的行顺序；不做无限滚动；手机版在原计划第 5 步里一起用上。

## 方案
只有一种合适做法：在 `lib.js` 加通用小工具 + `lifeos.css` 加通用样式，各面板只套 class / 调一个函数。翻页用横向 scroll-snap 轨道（这样箭头和触控板都能翻），不用自己算动画；滑动用 `overflow-y:auto` + 底部渐隐遮罩。
