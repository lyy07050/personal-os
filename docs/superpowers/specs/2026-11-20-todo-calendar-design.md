# 今日待办「＋」、待办卡片、可翻周的日程 · 设计（短）

日期：2026-11-20 · 状态：待 Charlotte 确认

## 为什么

首页的「今日待办」现在只会自动汇总（截止、面试、复盘三件要事、项目），随手想到的待办没地方加；
「本周日程」只能看本周，也没地方加自己的日程。Charlotte 要在面板上直接加待办、加日程，像苹果日历一样翻到下周、下下周。
只要打开面板能看到就够了，不需要提醒。

## 目标

1. 首页「今日待办」右上角「＋」：输入一句话、回车，加一条待办，能打勾。
2. 随手记新增类型 `待办`；「我想记…」也能直接存成待办。
3. 今天的日程也出现在今日待办里（右边写时间）。
4. 「本周日程」可以左右翻周、回到本周，「＋」加日程（日期、可选时间、事情）。
5. 日历显示：自己加的日程、作业截止、活动卡、课、面试；以后 Quercus 的课程活动（Task 8）。

## 数据格式

- **待办卡片**（和其他随手记卡一样，一张一篇，在 `00 随手记/`）：
  ```
  ---
  type: 待办
  done: false
  date: 2026-11-21     # 可选：哪天要做；不写 = 随时
  created: 2026-11-20
  ---
  买鸡蛋和牛奶
  ```
  打勾 → `done: true` 并加 `done_on: <今天>`；再点一次恢复 `done: false`、删掉 `done_on`。
- **日程**：一个文件 `10 总部/日程.md`，一行一个，按日期排：
  `- 2026-11-29 15:00 和朋友吃饭` · 全天写成 `- 2026-11-29 和朋友吃饭` · 可选 `[地点:: Bahen]`。
  Task 8 的 Quercus 同步以后写在这个文件的 `<!-- quercus:start -->` / `<!-- quercus:end -->` 标记段里，手写的行不动。
- `lint_vault.py`：认识 `type: 待办`（`done` 必须是 true/false，`date` / `done_on` 是日期）；检查 `日程.md` 每行的日期、时间格式。
- `make_samples.py`：加几张示例待办卡和几行示例日程（有本周、下周、下下周的）。

## 今日待办怎么排

现有的几类照旧（今天的截止、面试、复盘三件要事、项目），再加：
- 待办卡：`done: false` 且（没写 `date` 或 `date` ≤ 今天）；今天打过勾的（`done_on` = 今天）留在列表里显示划线。
- 今天的日程（`日程.md` 今天的行 + 今天的活动卡）：右边写时间（全天写「今天」），**没有勾选框**（日程不是做完的事），用一个小圆点代替。
- 每周固定的课**不**放进待办。
- 顺序：有时间的按时间先，然后截止、待办卡、三件要事、项目。

## 界面

```
今日待办                                 ＋
  ○ Manulife 面试                    15:00
  · 和朋友吃饭                        18:00   ← 日程：圆点，不能勾
  ○ 买鸡蛋和牛奶                   errands
  [ 加一条待办…                          ]   ← 点＋后出现，回车保存、Esc 收起

本周日程  ‹  2026年11月 · 23–29日  ›  回到本周                    ＋
```
- 翻周只改面板里显示的那一周（记在内存里，重新打开回到本周）；标题日期跟着变；不是本周时「回到本周」才显示。
- 日程「＋」：一小块表单（日期默认显示中那周的今天或周一、时间可空、事情），保存后马上出现在格子里。
- 「我想记…」旁边加一个小开关「待办」：打开时存成待办卡，关着时照旧存成随手记卡。手机首页同样。
- 手机首页的今日待办也加「＋」；手机上不做日历翻周（手机首页没有周日历）。
